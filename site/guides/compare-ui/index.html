FastPin guide · macOS & Windows

Compare UI changes with a pinned screenshot

Keep the previous state visible while you inspect a new layout. A pinned crop gives you a reference as you switch tabs or open the application you are reviewing.

Use this for a visual check of one component. It is not an automated pixel diff or a guarantee of design accuracy; browser zoom, display scaling and image zoom can change the apparent size.

Capture this reference card

This is fictional website content for the exercise, not a screenshot of FastPin. Capture just the card, then pin it before scrolling to the changed version.

Capture, pin, then keep working

  1. Open FastPin and finish its permission setup. On macOS, check Screen Recording, Accessibility and Input Monitoring in Diagnostics if capture does not start.
  2. Press Ctrl + Shift + 2 and drag around the reference below. On macOS, double-tapping left Command is another capture trigger. Use your configured shortcut if you changed the defaults.
  3. Press Space to pin the selection. Drag the pin beside the area you are working on; scroll over the pin to adjust its size.
  4. Switch to your editor or scroll to the comparison task. The pinned image should remain visible. Hover over the pin and press Space for its tools.
  5. Press Escape while the pin is active to close it. Ctrl + Shift + 4 restores the last image if you closed it too soon.

Compare against the changed card

Keep the reference pin visible beside this card. Look for changes in the status, the amount of spacing, and the action label. The cards below are static examples; their buttons do not download anything.

What changed?

The action changed from “Download report” to “Open report”, and the card padding increased from 20 to 32 pixels. The heading, export status and row count stayed the same. A visual difference does not by itself tell you whether the change is correct.

The exercise is complete when the reference stays visible while you inspect the current card, and you can identify both intentional changes.

Make the comparison fair

  • Keep browser zoom and display scale consistent between captures.
  • Capture the same component boundary and avoid comparing a zoomed pin as if it were a pixel-accurate overlay.
  • Use annotations to point out one difference. Confirm it in the live interface before filing a report.

Try it with FastPin

FastPin is a free, open-source desktop preview. macOS builds require macOS 14+ on Apple Silicon and are not notarized yet. The Windows x64 preview requires Developer Mode and one PowerShell registration. Read the installation steps before downloading.
