FastPin guide · macOS & Windows

Keep an API response beside your editor

Keep the fields you need in view while you write the code that consumes them. A small pinned image can be useful when switching between a browser, a terminal response and your editor.

Use it for a short reference that fits in one crop. Keep the original response open when you need searchable text, more rows or fresh data: a pin is a snapshot, not a live API view.

A reference you can capture

This fictional response contains no credentials or personal data. Crop the code block with FastPin, then use the task below to check whether the pin remains useful while you move around.

Capture, pin, then keep working

  1. Open FastPin and finish its permission setup. On macOS, check Screen Recording, Accessibility and Input Monitoring in Diagnostics if capture does not start.
  2. Press Ctrl + Shift + 2 and drag around the reference below. On macOS, double-tapping left Command is another capture trigger. Use your configured shortcut if you changed the defaults.
  3. Press Space to pin the selection. Drag the pin beside the area you are working on; scroll over the pin to adjust its size.
  4. Switch to your editor or scroll to the comparison task. The pinned image should remain visible. Hover over the pin and press Space for its tools.
  5. Press Escape while the pin is active to close it. Ctrl + Shift + 4 restores the last image if you closed it too soon.

Try it beside your code

Switch to a scratch file in your editor. With only the pin for reference, write down the field paths for the job status, exported row count and download location. Keep the image small enough that it does not cover the code you are editing.

Check the field paths

state, result.rows and result.download_path. job_id identifies the job; it is not its status.

You have completed the exercise when you can read those three paths while your editor is active. This checks reference visibility; it does not test or validate an API integration.

Keep the reference small and safe

  • Crop only the relevant fields, rather than a whole terminal window.
  • Do not include API keys, access tokens or private customer records in screenshots you plan to share.
  • Recapture after a schema changes. The pinned image does not update with the source.

Try it with FastPin

FastPin is a free, open-source desktop preview. macOS builds require macOS 14+ on Apple Silicon and are not notarized yet. The Windows x64 preview requires Developer Mode and one PowerShell registration. Read the installation steps before downloading.
