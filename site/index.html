macOS

macOS 14+ · Apple Silicon
Download for Mac

Open the DMG and drag FastPin into Applications. It lives in the menu bar and updates itself.

Install notes

Previews are not notarized yet. If macOS blocks the first launch, follow Apple's instructions. Allow Screen Recording when asked; Accessibility enables Element detection, mouse shortcuts and double-tap Control.

Windows

Windows 10 2004+ / 11 · x64
Download for Windows

Extract the ZIP into a permanent folder, then register it once and launch from Start.

Install notes

Turn on Developer Mode, open PowerShell in the folder and run Add-AppxPackage -Register "$PWD\AppxManifest.xml". Windows updates are manual for now.
