macOS

macOS 14 以上 · Apple 晶片
下載 Mac 版

預覽版尚未經 Apple 公證。打開 DMG 並拖進「應用程式」；若開啟被擋下，請看下方安裝說明。

安裝說明

預覽版尚未經過 Apple 公證。如果第一次開啟被 macOS 擋下，請參考 Apple 的說明。引導會自動檢查「螢幕錄製」、「輔助使用」和「輸入監控」。輔助使用用於元素偵測及滑鼠快捷鍵；輸入監控用於兩種雙擊手勢。

Windows

Windows 10 2004 以上 / 11 · x64
下載 Windows 版

開發者預覽版：需要開啟「開發人員模式」並用 PowerShell 註冊一次。請解壓到固定資料夾，詳見下方說明。

安裝說明

先開啟「開發人員模式」，在該資料夾開啟 PowerShell，執行 Add-AppxPackage -Register "$PWD\AppxManifest.xml"。Windows 版目前需要手動更新。
