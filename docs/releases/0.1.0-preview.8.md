# FastPin 0.1.0 Preview 8

- **Select and translate:** Ctrl+Shift+6 starts a green text selection. Release to show a translation card immediately, with recognition and translation progress in the same card. Ctrl+Shift+2 keeps the blue screenshot selection; existing custom capture bindings are preserved. Translation no longer replaces the clipboard.
- **Offline words, online sentences:** bundled CC-CEDICT handles words and known short phrases. Sentences use MyMemory's free online service. The selected sentence is sent to MyMemory; no LLM, account or API key is required. Unlisted words stay offline until Online is selected.
- **A small floating card:** milk-white translucent background, green border, system pronunciation, copy and close controls. Dismissing a pending result keeps the card closed.
- **Native macOS settings and updates:** Settings, Shortcuts and About use AppKit. About can check for signed updates, download them and update/restart. FastPin stays in the menu bar without a Dock icon; opening the menu does not open the control panel.
- **Capture hints:** the bottom-left hint panel shows shortcuts for the current capture, translation or text-editing mode.
- **Edit text again:** with Text selected, click an existing annotation to edit it; undo/redo includes text changes.
- **Background OCR:** copying text no longer opens the control panel.
- **Safer default shortcut:** Dictionary moved from Ctrl+D to Ctrl+Shift+6 so it no longer takes over end of input in terminals, forward delete or browser bookmarks. Preview 7 settings that still use the old Ctrl+D default move automatically; a Ctrl+D you choose and apply again is kept.

## Install and update

macOS: Apple Silicon, macOS 14+. Download the DMG and drag FastPin into Applications. Previews before this release have no in-app updater and need this one manual installation. This development preview is not notarized; replacing an older signing identity can require regranting macOS permissions.

Windows: x64, Windows 10 version 2004+ / Windows 11. Extract the ZIP into a permanent folder, enable Developer Mode, register the unpacked application with `Add-AppxPackage -Register "$PWD\AppxManifest.xml"`, and launch from Start. Windows updates remain manual.

The release includes SHA-256 checksums, the signed macOS update feed and third-party notices in the application packages. The dictionary's CC BY-SA 4.0 license is separate from the application's MIT license. See [Quick Start](../../GETTING_STARTED.md) and [update details](../UPDATES.md).
