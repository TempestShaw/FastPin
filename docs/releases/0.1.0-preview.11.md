# FastPin 0.1.0 Preview 11

- **Double-tap left Command to capture on macOS.** Replaces the left Shift gesture to avoid accidental screenshots while typing. Double-tap Control still starts translation; Space pins the selection. Ctrl+Shift+2 remains available.
- **No modifier-chord activation.** Right Command, Command with another key, other held modifiers and long holds do not count as clean taps.
- **Retire left Shift.** Its monitor and settings control are removed; the old preference is disabled when the new version starts. Settings → Shortcuts and Diagnostics show left Command instead.
- **Updated guides.** Website and README describe the current gestures. The macOS bundle and updater declare the minimum supported version, macOS 14.

## Install and update

On macOS, open About → Check for Updates. Signed incremental updates are provided where available, with full archive fallback. Windows updates remain manual; the modifier double-tap changes are macOS-only.

This is a manually published, **non-notarized preview**, signed with the same persistent development identity as Preview 10. Existing grants should carry over from that identity; upgrades from older ad-hoc or differently signed versions may require a one-time permission repair. Sparkle update signatures do not replace Developer ID signing or Apple notarization.
