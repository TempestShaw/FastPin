# FastPin 0.1.0 Preview 12 (draft)

- **Faster capture start.** After a shortcut or double tap, the selection screen appears in about half the time (about 230 ms down to 125 ms on a two-display Mac). FastPin no longer waits before grabbing the screen unless a menu or one of its own windows has to disappear first, the screen under the pointer is shown first, and the shortcut hint is laid out once.
- **Double-tap Control reacts on the second press.** Translation starts as soon as Control goes down the second time instead of when it is released. Left Command still waits for a clean second release, because Command starts most chords (Command+Tab, Command+C).

## Install and update

On macOS, open About → Check for Updates. Windows updates remain manual.
