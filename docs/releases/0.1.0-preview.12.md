# FastPin 0.1.0 Preview 12

- **Translation card follows its background on macOS.** The card samples what is behind it and switches between light and dark text, so it stays readable over any window. It uses a clearer native backdrop and never asks for a new permission. On Windows the card keeps a solid light background.
- **Long text goes to the browser.** Text beyond MyMemory's 500-byte limit now links to Google Translate instead of asking for a shorter selection. Longer text is split into numbered parts, each short enough for the browser and Google Translate to open.
- **Faster shortcuts.** The capture overlay opens sooner after a shortcut or double tap, and double-tap Control fires on the second press.
- **Windows fixes.** The panel now shows `Ctrl ×2` for the double-tap gesture instead of naming the wrong key. Each Windows build now has its own package version, so a newer preview counts as an upgrade.

## Install and update

On macOS, open About → Check for Updates. Signed incremental updates are provided where available, with full archive fallback. Windows updates remain manual: extract the new ZIP into a permanent folder and register it again.

This is a manually published, **non-notarized preview**, signed with the same persistent development identity as Previews 10 and 11. Existing grants should carry over from that identity; upgrades from older ad-hoc or differently signed versions may require a one-time permission repair. Sparkle update signatures do not replace Developer ID signing or Apple notarization.
