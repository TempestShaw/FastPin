# FastPin 0.1.0 Preview 10

- **Independent capture and translation on macOS:** double-tap left Shift alone to capture; double-tap Control to translate. Select a region and press Space to pin. Right Shift, uppercase typing and modifier chords do not count as capture taps. Both gestures can be disabled in Settings → Shortcuts. Ctrl+Shift+2 and Ctrl+Shift+1 remain available; Ctrl+S is not a default global shortcut.
- **Permission onboarding:** Screen Recording, Accessibility and Input Monitoring are checked automatically. Setup can continue only after all three are ready; interrupted setup resumes at the permission page. Permission grants re-enable the gesture monitors.
- **Control gesture monitoring:** use a permission-checked, listen-only macOS event tap. Input Monitoring is required for both gestures; Accessibility enables Element detection and mouse shortcuts.
- **Diagnostics:** native Settings → Diagnostics shows the running path, signature, permissions and gesture monitor registration. Recheck and copy a report without screenshots, OCR or translation contents.
- **One running instance:** repeated launches forward settings/image requests to the existing process rather than competing for shortcuts.
- **Repository layout:** application sources, platform integrations, tests, packaging and scripts are grouped by purpose.

## Install and update

macOS: Preview 8 and later update from About → Check for Updates. Windows updates remain manual. See [Quick Start](../../GETTING_STARTED.md) and [update details](../UPDATES.md).

## macOS preview signing

This preview is signed with a persistent local development identity and is **not Apple-notarized**. It is a manually published preview exception while Developer ID enrollment is pending. The first upgrade from earlier ad-hoc-signed previews or another signing identity may require removing and re-adding FastPin in macOS privacy settings. Sparkle verifies the update archive independently; it does not grant system permissions. Quit older FastPin copies before the first installation of this version.
