# FastPin 0.1.0 Preview 9

- **Double-tap Control to translate:** tap Control twice quickly, select text and release. One key, one hand. Control used as a modifier (Ctrl+C, Ctrl-click), held down, or pressed with Shift, Option or Command never counts. Ctrl+Shift+1 keeps working.
- **Easy to turn off:** Settings → Shortcuts has a "Double-tap Control to translate" checkbox. On macOS the gesture needs Accessibility permission, which FastPin asks for once; the panel shows the gesture next to the Dictionary shortcut while it is active.

## Install and update

macOS: Preview 8 and later update from About → Check for Updates. Windows updates remain manual. See [Quick Start](../../GETTING_STARTED.md) and [update details](../UPDATES.md).
